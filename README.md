# 🎣 Marea — Shared Trips & Adventures

**Marea** is an intuitive, collaborative web application designed to plan weekend getaways, group trips, and fishing expeditions with friends. It allows you to organize event schedules, confirm attendance, assign equipment/tasks, and manage shared expenses fairly and transparently.

---

## ✨ Key Features

### 📅 Event Agenda & Attendance Voting
* **Interactive Calendar:** View confirmed events and proposed dates with open voting.
* **Attendance Voting:** RSVP ("I'm in!") or vote on proposed dates for the next trip.
* **Event Overview:** Details about destination, status (*Confirmed / Voting Open*), and avatars of confirmed participants.

### 📝 Collaborative Checklist
* **Equipment & Task Tracker:** Interactive checklist with progress percentage (never miss the *Rods & Reels, Bait & Hooks, Ice & Cooler*).
* **Assignee Tracking:** Clearly see who is responsible for bringing each item.

### 💰 Split Expense Management
* **Custom Expense Logging:** Input items and costs, selecting **who paid** and **who shares the expense** (beneficiaries).
* **Automated Balance Calculation:** Smart settlement algorithm to balance debts simply.
* **Event Summaries:** Overview of total event expenditures and individual breakdowns.

### 🎨 Customization & User Preferences
* **Theme Toggle (Dark / Light Mode):** Effortlessly switch visual styles according to each user's preference.
* **User Profiles:** Customized avatars and initials for each group member.
